File details and visibility

1. File Access Keys

Reads this protected file only. Cannot upload, edit, or delete. Copy new keys once; they cannot be retrieved later.

Leave intentionally blank for the file’s lifetime, bounded by your account key. For permanent files, valid until revoked.

2. View Links

Browser access using a File Access Key’s expiration. Anyone with the link can read the file until it expires or is revoked.

3. Temporary Access Links

Short-lived sharing with its own lifetime, bounded by the file and issuing credential.

The server’s configured maximum applies.
Move, retention, and deletion

Move file

Existing shared URLs stop working after a move. File Access Keys remain valid.

Change retention

Measured from the original upload, not today. Empty means permanent storage if your account permits it. Updating retention invalidates existing browser links.

Delete file

Permanently removes the file and invalidates every associated key and link.

Revoke shared access

Revoking browser links leaves keys active. Revoking all shared access also invalidates every file key. Your account permissions remain active.

Open a Protected File

A View Link follows its key’s lifetime. A Temporary Access Link expires sooner. Open either directly; use this form when you received a file URL and File Access Key.

The key is sent in an authorization header to the configured CDN, never included in the browser URL.
